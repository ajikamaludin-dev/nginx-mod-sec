## Nginx with ModSecurity Docker Image

Custom Docker image with Nginx and ModSecurity (OWASP CRS) for enhanced web application security.

### Features

- Nginx 1.29.3 with HTTP/3 (QUIC) support
- ModSecurity v3 with OWASP Core Rule Set (CRS) v3.3
- Pre-configured security headers
- Optimized TLS configuration
- Built-in protection against common web attacks

### Quick Start: Build the image:

```bash
docker build -t yourimage:tag .
```
